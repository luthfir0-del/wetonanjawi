# Wetonan Jawi — versi awal

Website statis satu file, tanpa dependensi atau proses build.

## Cara mencoba
Buka `index.html` di browser.

## Cara menerbitkan melalui GitHub Pages
1. Buka repository `wetonanjawi`.
2. Klik **Add file** → **Upload files**.
3. Upload `index.html` dari folder ini, lalu klik **Commit changes**.
4. Buka **Settings** → **Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main`, folder `/(root)`, lalu **Save**.
7. Tunggu publikasi dan buka URL GitHub Pages yang ditampilkan.

## Catatan kalkulator
Perhitungan memakai acuan 17 Agustus 1945 = Jumat Legi dan siklus pasaran lima hari. Verifikasi dengan beberapa kalender Jawa tepercaya sebelum mengandalkan hasil untuk penggunaan adat/resmi.
